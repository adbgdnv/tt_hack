Агент разбирает отчёт о контрагенте, обращает внимание на риски и отвечает на

## Раскладка

Весь продуктовый код под `src/`. Ядро — `src/core`, приложения — `src/api` и
`src/mcp_server`. **В приложениях нет бизнес-логики, только вызовы в ядро.**
Проверяется механически: удали одно приложение — второе работает.

Каталог называется `mcp_server`, а не `mcp`: при раскладке `where = ["src"]`
пакет `mcp` перекрыл бы одноимённую библиотеку.

## Требования кейсодателя, влияющие на код

- **Светофор банка — источник истины.** Свой скоринг не строим, объясняем готовый.
  «Мы просто за базу посчитаем, что светофор верный и это единственный источник истины».
- **Агент рекомендует, а не выносит вердикт.** «Только рекомендует и обращает внимание
  человека». Формулировки «не заключать договор» — за рамками.
- **Отсутствие данных — это ответ.** «Если нет судебных дел, это не значит что их нет.
  Тогда говорим, что невозможно оценить по конкретно этому критерию».
- **Ранжирование со скором не нужно.** При сравнении нескольких — вывод «с кем лучше
  не общаться», без рейтинговой таблицы.
- **Роли не разделяем.** Один режим, «анонимный предприниматель», интересуют все блоки.
- **Графики обязательны.** Упомянуты трижды, названы дырой текущего продукта.
- Память — в рамках одной сессии. Между сессиями не храним.
- Требований по времени ответа нет, но прогресс в интерфейсе показывать надо.

## Данные

Выгрузка кейсодателя в `docs_alpha/` (вне репозитория, подключается симлинком `data`).
**200 компаний, а не 100:** JSON и CSV — разные наборы, пересечение по ОГРН нулевое.

Ловушки, проверенные на всех 200:

- Суммы больше 2³¹ приходят как `{"$numberLong": "..."}` — и это ровно самые крупные
  дела (4,5 и 3,0 млрд ₽). Без распаковки они выпадают из обработки.
- Код `аrbitrationDefendant` среди позитивных факторов написан с кириллической «а»
  (U+0430), среди негативных — с латинской. Сравнение строк промахивается.
- `defandantArbitration` — опечатка в схеме источника, по всему файлу.
- Все 200 в статусе `CURRENT`. 50 из 200 — ИП: у них не бывает отчётности,
  учредителей и уставного капитала.
- Отбор полей сжимает отчёт в 74–390 раз. Это не оптимизация: без него бесплатный
  тариф Groq (8K токенов/мин) непригоден.

## Провайдер модели

Groq требует заголовок `User-Agent` — без него Cloudflare отдаёт `403`. curl
подставляет свой сам, из Python задаём руками.

`gpt-oss-20b` возвращает поле `reasoning` рядом с `content`. Пользователю не
показываем, но в бюджет токенов закладываем.

Базовый URL держим переменной окружения `LLM_BASE_URL` — смена провайдера или
подключение прокси не должны трогать код.

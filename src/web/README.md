# Веб-интерфейс

Пока заглушка — папка занята, чтобы место было очевидно, а фронт делается позже.

## Что здесь будет

Чат с агентом плюс виджеты. За основу кейсодатель предложил «ChatGPT с модификациями»:
графики и статистика рядом с диалогом. Графики он упоминал трижды и назвал их отсутствие
болью текущего продукта.

## Что уже решено

**Стек — Vite + React + TypeScript.** Отдельный процесс на `:5173`, ходит в API по HTTP.
CORS для этого порта уже прописан в `src/api/main.py`.

**Дизайн-система — `@alfalab/core-components`**, её рекомендует само описание кейса.
Подробности и подводные камни — в скилле `alfa-core-components` (проектный уровень,
`.claude/skills/`). Коротко: устанавливать по компонентам, тему подключать отдельно из
`@alfalab/core-components-themes`, размеры числовые (`size={48}`), а не буквенные.

**Прогресс показывать обязательно.** Требований по времени ответа нет — кейсодатель
сказал, что это не метрика. Но добавил: если долго и на интерфейсе ничего не происходит,
«это уже вопросики». Значит статусы стримить.

## Запуск (когда появится)

```bash
npm install
npm run dev          # http://localhost:5173
```

API должен быть поднят: `make up` в корне репозитория.

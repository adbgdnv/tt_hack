# Quickstart — как убедиться, что графики работают

---

## Предварительно

```bash
make data && python3 scripts/build_dataset.py     # 200 контрагентов
```

## 1. Правила достаточности данных

```bash
pytest tests/test_charts.py -q
```

Проверяется то, что глазами не поймать:

| Что | Почему важно |
|---|---|
| Ни у одной из 200 компаний нет графика с одной точкой | одна точка создаёт впечатление динамики, которой нет |
| Ни одного описания без данных | пустая рамка выглядит как поломка |
| У 178 компаний есть хотя бы один график, у 22 — ни одного | цифры должны сойтись с замерами |
| Числа на графике совпадают с фактами того же раздела | иначе экран противоречит сам себе |
| У предпринимателей финансовых графиков нет | и формулировка не «мало данных» |

## 2. Покрытие на живых данных

```bash
make up
curl -s localhost:8000/counterparties/5032257375/report | python3 -c "
import json,sys
d = json.load(sys.stdin)
for s in d['sections']:
    for c in s.get('charts', []):
        print(f\"{s['title']}: {c['title']} — рядов {len(c['series'])}, точек {len(c['labels'])}\")"
```

**МАКСМАРКЕТ** — ожидаются графики в разделах «Финансы», «Суды» и «Исполнительные
производства»: у него есть и отчётность за три года, и иски, и 507 производств.

```bash
curl -s localhost:8000/counterparties/772377037026/report   # ИП: финансовых графиков нет
curl -s localhost:8000/counterparties/2466177504/report     # из плоской выгрузки
```

Компания из тех 22, у которых графиков нет вовсе:

```bash
python3 -c "
import sys; sys.path.insert(0,'src')
from core import repo, report
пустые = [r for r in repo.all() if not any(s.charts for s in report.build(r).sections)]
print(f'без графиков: {len(пустые)}')
print('пример:', пустые[0]['baseInfo']['inn'], пустые[0]['baseInfo']['shortName'])"
```

## 3. Интерфейс

```bash
cd src/web && VITE_API_BASE=http://localhost:8000 npm run dev
```

| Проверка | Ожидается |
|---|---|
| `5032257375` МАКСМАРКЕТ | графики в трёх разделах, разделы с сигналом выше |
| `772377037026` ИП | в финансах «у ИП такого не бывает», графика нет |
| Компания из списка без графиков | нигде не пустая рамка и не ось без значений |
| Пройти по 10 разным компаниям | ни одного графика из одной точки |
| Сверить число на графике с фактом раздела | совпадает |
| Разброс величин | у компании с активами 279 млрд ₽ и у компании с 1,9 млн ₽ обе оси читаемы |

## 4. Печать

Нажать «Распечатать» на компании с графиками.

**Ожидается**: графики в предпросмотре целиком, значения подписаны на них — на бумаге
нет наведения мышью, и график без подписей превращается в картинку без чисел.
Панели диалога и кнопок быть не должно.

## 5. Сборка и стиль

```bash
ruff check . && pytest -q
cd src/web && npx tsc -b && npm run build
```

---

## Признак готовности

Пользователь называет направление изменения выручки за пять секунд, не читая чисел,
и различает преимущественного истца от преимущественного ответчика с первого взгляда.
Ни одной пустой рамки на 200 компаниях.

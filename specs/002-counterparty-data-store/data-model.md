# Phase 1 — модель данных

Каноническая форма, к которой приводятся обе выгрузки. После приведения потребитель
не может определить, из какой выгрузки пришёл контрагент, — это проверяемое свойство
(US3, сценарий 2).

---

## Контрагент

Единица набора. Опознаётся по ИНН, который уникален внутри набора: проверено, что
пересечение выгрузок по ИНН и ОГРН пустое, дублей нет.

Структура повторяет спецификацию кейсодателя `data/GetFullReportResponse.md` — своей
схемы не изобретаем, иначе разойдёмся с источником и с будущим настоящим API.

| Группа | Что несёт | Заполнено |
|---|---|---|
| Идентификация | ИНН, ОГРН, краткое и полное наименование, ОКПО | 200/200 |
| Регистрация | дата регистрации, лет с регистрации, статус, адрес, КПП | 200/200 (адрес и КПП — 150) |
| Оценки риска | уровень риска банка, уровень «Знай своего клиента» | 200/200 |
| Репутационные факторы | негативные и позитивные, каждый с кодом, описанием и разделом | негативные у 116, позитивные у 200 |
| Руководство и учредители | руководитель, учредители с долями, связанные организации | 150 |
| Деятельность | основной и дополнительные виды, налоговый режим | 200 / 150 |
| Суды | сводка по статусам, разбивка по годам с суммами в ролях истца и ответчика | 161 и 101 |
| Исполнительные производства | номер, дата, сумма, признак активности | 143 |
| Проверки и лицензии | контролирующий орган, даты, статус | 59 и 22 |
| Финансы | выручка, прибыль, активы, пассивы по годам; коэффициенты | 144 и 47 |
| Госзакупки | тендеры и контракты по годам | 109 |

## Три разных «пусто»

Различение обязательно: по требованию кейсодателя отсутствие данных — это ответ,
а не отсутствие риска. Смешать их — значит выдать «мы не знаем» за «всё чисто».

| Состояние | Что означает | Как выражено | Пример |
|---|---|---|---|
| **Есть значение** | факт известен | значение на месте | 54 активных производства |
| **Нет данных** | источник не содержит сведений | поля нет либо оно пустое | у компании нет раздела судов — оценить по этому критерию невозможно |
| **Неприменимо** | сущности не существует для этой формы | поля нет, но причина известна из формы контрагента | у индивидуального предпринимателя не бывает бухгалтерской отчётности, учредителей и уставного капитала |
| **Ноль** | факт известен и равен нулю | явный ноль | ноль дел в роли ответчика при заполненном разделе судов |

«Неприменимо» выводится из формы контрагента, а не хранится отдельным признаком:
пятьдесят контрагентов из двухсот — предприниматели, и ни у одного из них нет
ни финансовой отчётности, ни сведений об учредителях. Это устройство формы,
проверенное на всех пятидесяти.

## Оценки риска

Две независимые оценки от разных организаций. Обе переносятся как есть и не
пересчитываются — по требованию кейсодателя они источник истины и подлежат объяснению.

**Уровень риска банка** — скоринг банка по нераскрываемой методологии:

| Значение | Смысл | Сколько |
|---|---|---|
| низкий | надёжный контрагент | 163 |
| средний | требует внимания | 26 |
| высокий | в зоне риска | 5 |
| **нет данных для оценки** | оценить невозможно | 6 |

Четвёртое значение в спецификации кейсодателя не описано, но приходит в данных.
Схлопывать его ни в низкий уровень, ни в высокий нельзя: это «не знаем», а не «чисто».

**Уровень «Знай своего клиента»** — агрегация платформы Центробанка: зелёный 158,
жёлтый 40, красный 2.

фактора есть поле раздела, и придумывать разбиение не требуется.

| Раздел | Негативных факторов | Позитивных |
|---|---:|---:|
| суды | 32 | 68 |
| реестры | 29 | 788 |
| виды деятельности | 25 | 75 |
| исполнительные производства | 18 | 82 |
| финансы | 7 | 136 |
| руководство | 3 | 297 |
| связанные организации, лицензии, сайт, филиалы | 0 | 83 |

## Временные ряды

Два ряда пригодны для показа динамики, оба лежат готовыми и не требуют вычислений:

| Ряд | Из чего | Есть у |
|---|---|---|
| Выручка, активы, пассивы по годам | финансовая отчётность, до трёх лет | 144 из 200 |
| Иски по годам в ролях истца и ответчика | судебная разбивка, до четырёх лет | 101 из 200 |
| Коэффициенты устойчивости, платёжеспособности, рентабельности | готовые коэффициенты | 47 из 200 |

Прибыль заполнена у 72 контрагентов против 124 у выручки — почти вдвое реже.
Пара «выручка и прибыль» по умолчанию не строится: прибыль отваливается у большинства.

## Правила приведения

Применяются на шаге сборки, к результату применяться уже не должны.

1. **Развёртка плоской записи.** Ключ вида `путь[индекс].подпуть` превращается
   во вложенную структуру со списками. Без этого запись распадается на ключи
   с индексами в имени, и все списочные разделы пропадают.
2. **Типы по карте.** Тип каждого пути берётся из вложенной выгрузки и применяется
   к плоской. Текст `false` в поле-признаке становится отрицанием, а не непустой строкой.
3. **Развёртка обёрток.** Большие суммы и даты, записанные обёртками, превращаются
   в числа и строки. Затрагивает 67 значений по 16 путям, все — во вложенной выгрузке.
4. **Опечатки схемы сохраняются.** Раздел судов в роли ответчика записан в источнике
   с опечаткой в имени. Она есть и в спецификации, и в данных; исправлять нельзя —
   разъедется с источником.
5. **Код фактора сверяется точно.** Один из позитивных кодов записан с кириллической
   буквой в начале при латинском написании того же кода среди негативных. Сравнение
   по строке промахивается; проверено, что других кодов с не-латинскими символами нет.
6. **Имя поля берётся из данных.** Признак активности учредителя в спецификации назван
   иначе, чем в выгрузке. Каноническим считается написание из данных.

## Набор

Результат сборки: последовательность записей контрагентов в канонической форме плюс
сведения о самой сборке — когда собран, из каких выгрузок, сколько записей.

Инварианты, проверяемые тестом на собранном наборе:

- ровно двести записей, ИНН уникальны;
- ни одна запись не состоит только из наименования и ИНН;
- доля активных исполнительных производств совпадает с исходными выгрузками —
  признак не перевернулся при приведении типов;
- все значения, записанные обёртками, читаются как числа, ни одно не потеряно
  и не обнулено;
- доля заполненных разделов у контрагентов из разных выгрузок сопоставима.

# Контракт: подготовленный набор

Договор между шагом сборки и всеми потребителями данных. Меняется только вместе
с обеими сторонами.

---

## Что это

Один файл, собранный заранее из обеих выгрузок кейсодателя. Сервер читает его при
старте и держит в памяти. В рантайме файл не перечитывается и не изменяется.

Формат — JSON: последовательность записей контрагентов в канонической форме
(см. [data-model.md](../data-model.md)) и сведения о сборке.

## Сведения о сборке

Каждый набор несёт: время сборки, перечень исходных выгрузок с их размерами,
число записей и версию правил приведения. Этого достаточно, чтобы при расследовании
отличить «сервер читает старый набор» от «в наборе действительно нет этой компании».

## Гарантии, которые даёт сборка

Потребитель вправе на них полагаться и не обязан их перепроверять:

1. Все записи в одной форме. Определить по содержанию, из какой выгрузки пришёл
   контрагент, невозможно.
2. Типы приведены: числа — числами, признаки «да/нет» — признаками, даты — строками
   в едином виде. Текстовых `false`, читаемых как истина, в наборе нет.
3. Большие суммы развёрнуты из обёрток в числа. Ни одно значение не потеряно и не
   обнулено.
4. Отсутствующее поле отсутствует, а не заменено нулём или пустой строкой.
   Различение «нет данных» и «ноль» сохранено.
5. ИНН уникален. Записей ровно столько, сколько контрагентов в исходных выгрузках.

## Чего сборка не делает

- **Не сокращает запись.** Отбор полей — забота отдачи, не хранения.
- **Не пересчитывает оценки риска.** Они переносятся как есть.
- **Не чинит опечатки источника.** Имена полей сохраняются в написании выгрузки,
  включая опечатку в разделе судов и кириллическую букву в одном из кодов факторов.
- **Не изменяет исходные выгрузки.** Они материалы кейсодателя, доступ только на чтение.

## Где лежит

Путь задаётся переменной окружения. Значение по умолчанию — каталог `dataset/`
в корне репозитория, добавленный в `.gitignore`.

Каталог `data/` под набор не занимается: локально это симлинк на материалы кейсодателя.

## Как попадает на сервер

Собирается локально, переносится копированием. В репозиторий и в файлы, отдаваемые
браузеру, не попадает — репозиторий открыт, а в данных сведения об учредителях,
включая имена и личные идентификаторы.

Автодеплой набор не переносит: он занимается только собранным интерфейсом и намеренно
не трогает серверную часть.

## Что происходит при недоступности

Сервер не запускается и сообщает явной ошибкой, какого файла не хватает. Работа
с пустым набором запрещена: она выглядит как «у всех компаний ничего нет» и неотличима
от честного результата.

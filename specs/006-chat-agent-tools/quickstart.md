# Проверка фичи

Опорная компания — **ООО «МАКСМАРКЕТ», ИНН 5032257375**: оба светофора зелёные
при 2,6 млрд ₽ исков как ответчик, 54 активных производствах и процедуре
банкротства. У неё есть четыре графика из пяти — нет `revenue_assets`.

## Подготовка

```bash
uv pip install --python .venv/bin/python -e .
.venv/bin/python -m uvicorn api.main:app --app-dir src --reload   # 8000
npm --prefix src/web run dev                                       # 5173
```

Ключ поиска необязателен. Без `TAVILY_API_KEY` всё, кроме US4, работает — это
отдельный проверяемый сценарий, а не деградация.

## US1 — ответ идёт потоком

```bash
curl -N -X POST localhost:8000/chat/stream \
  -H 'Content-Type: application/json' \
  -d '{"message":"Сколько активных производств?","inn":"5032257375","session_id":"t1"}'
```

Ожидается: события `token` приходят по одному, видимой паузой между первым
и последним. Если весь ответ появился разом — стриминга нет, даже если формат верен.

Через прокси проверять обязательно отдельно: nginx буферизует по умолчанию,
и локально работающий поток снаружи приходит целиком.

## US2 — график по просьбе

В интерфейсе открыть 5032257375 и спросить:

| Вопрос | Ожидается |
|---|---|
| «Покажи суммы исков по годам» | график «Суммы исков по годам», числа 2024: истец 382 176 765, ответчик 2 589 790 444 |
| «Покажи выручку» | отказ: данных нет, названы доступные виды |
| «Построй круговую диаграмму» | называет доступные виды, не придумывает новый |

**Главная проверка честности**: после показа графика спросить «объясни его».
В ответе не должно быть ни одного года и ни одной суммы, которых нет в отчёте.
Именно здесь ломалась первая версия — дорисовывала 2019–2022 годы.

Числа сверять с дашбордом глазами: расхождение означает второй расчёт где-то
в коде, чего быть не должно.

Компания без единого графика — любая из 22; проверить, что просьба даёт отказ,
а не пустое полотно.

## US3 — видно, чем занят агент

При том же вопросе про график в ленте до появления графика должна возникнуть
строка вида «Строю график „Суммы исков по годам"». Имя функции с аргументами
пользователю показывать нельзя.

Проверить ошибку: временно сломать построитель и убедиться, что сбой виден
в ленте, а не проглочен.

## US4 — взгляд наружу

С ключом:

> «Есть ли новости о банкротстве этой компании?»

Ожидается два слоя: по отчёту — есть признак банкротства; во внешних источниках —
ссылки с пометкой «отчётом не подтверждено». На живой пробе возвращались
Контур.Фокус и Rusprofile.

> «Сколько активных производств?»

Поиск **не должен** вызываться: отчёт отвечает полностью.

Без ключа — оба вопроса отвечаются по отчёту, инструмент поиска модели
не предлагается.

Недоступность сервера поиска проверяется подменой адреса на заведомо мёртвый:
ответ по отчёту должен прийти целиком.

## Бюджет

Один вопрос с вызовом инструмента — около 5 300 токенов при лимите 8 000 в минуту.
**Два подряд на бесплатном ключе упрутся в лимит.** Проверять с паузой
или на платном ключе; на защите это ограничение обязано быть снято.

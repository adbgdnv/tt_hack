# Контракт инструментов агента

Инструментов два. Каждый добавленный инструмент стоит токенов на **каждом** вызове
модели при квоте 8 000 в минуту — список закрыт не из скромности, а по бюджету.

## `show_chart(kind)`

Показать пользователю график по компании в фокусе.

**Параметр** `kind` — один из пяти, каждый с русским названием прямо в описании:

```
plaintiff_defendant — «В какой роли судится»
balance             — «Чем обеспечены активы»
revenue_assets      — «Выручка и активы»
proceedings         — «Исполнительные производства»
arbitration_years   — «Суммы исков по годам»
```

Названия обязательны: без них модель выбирает по латинскому ключу и промахивается —
дважды на пробе выбрала «В какой роли судится» вместо «Суммы исков по годам».

**Результат** содержит две вещи сразу:

1. Побочный эффект — событие `chart` уходит в интерфейс, тот рисует график
   из загруженного отчёта.
2. Текст для модели — **числа этого графика**:

```
График «Суммы исков по годам» показан пользователю.
Данные: Как истец: 2023 5832755, 2024 382176765, 2025 0;
        Как ответчик: 2023 0, 2024 2589790444, 2025 21685219
```

Числа в результате обязательны. С голым подтверждением «показан» модель дописала
ответ выдуманной таблицей за 2019–2022 годы со ссылкой на несуществующий источник
(`research.md`, п. 1).

**Когда данных нет** — вместо отказа-заглушки называем доступное:

```
У этой компании нет данных для «arbitration_years».
Доступны: balance, plaintiff_defendant, proceedings
```

Событие `chart` при этом не отправляется, пустой график не рисуется.

**Источник чисел** — построители `core/charts.py`, те же, что рисуют дашборд.
Второго расчёта нет и быть не должно.

## `web_search(query)`

Поиск во внешних открытых источниках. Вызывается, только когда отчёт не отвечает
на вопрос.

**Параметр** — один: `query`. Своя узкая схема стоит около 60 токенов, тогда как
схема инструмента поставщика — 890: он предлагает глубину поиска, тему, срок,
списки доменов и прочее, что мы задаём сами.

**Под капотом** — вызов инструмента `tavily_search` на MCP-сервере поставщика
(`mcp.tavily.com`). Продукт выступает MCP-клиентом. Из пяти инструментов сервера
модели описан только поиск: все пять стоили бы 2383 токена на каждом вызове.

**Результат** — не более трёх находок, выдержки урезаются, каждая со ссылкой.
Побочно уходит событие `sources`.

**Когда ключа нет** — инструмент модели не предлагается вовсе. Не заглушка,
отвечающая «поиск недоступен»: описание неработающего инструмента стоило бы
токенов на каждом вызове.

**Когда сервер недоступен** — результат сообщает о неудаче, ответ по отчёту
продолжается. Внешняя система по сети отказывает чаще локального кода
и не может утаскивать за собой ответ.

## Предел шагов

Три шага на один вопрос. Двух хватает на «вызвал инструмент и ответил», третий
оставлен на случай двух инструментов подряд — такое наблюдалось: модель вызвала
`show_chart` дважды, исправляя собственный промах.

При достижении предела агент отвечает собранным. Без предела один вопрос способен
выесть минутную квоту целиком.

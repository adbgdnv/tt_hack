# Проверка фичи

Проверяется глазами: всё, что здесь есть, — про то, как выглядит ответ.
Опорная компания — **ООО «МАКСМАРКЕТ», ИНН 5032257375**: четыре графика
из пяти и богатый отчёт, на котором модель отвечает развёрнуто.

## Подготовка

```bash
npm --prefix src/web install
npm --prefix src/web run dev                                    # 5173
.venv/bin/python -m uvicorn api.main:app --app-dir src --reload  # 8000
```

## US1 — разметка разобрана

Спросить: **«Что настораживает в этой компании?»** — модель отвечает списком
с выделением.

| Что смотреть | Ожидается |
|---|---|
| `**жирный**` | жирный текст, звёздочек не видно |
| `- пункт` | маркированный список |
| `### Заголовок` | заголовок, решёток не видно |
| таблица | таблица; шире панели — прокручивается внутри себя |
| ссылка | открывается в новой вкладке |

Страница вбок ехать не должна ни при какой ширине таблицы — проверить, сузив
окно.

**Проверка на исполняемое**: задать вопрос так, чтобы модель повторила разметку
страницы (например попросить показать пример тега). В ответе должен быть текст,
ничего не выполняется и не пропадает со страницы.

## US2 — вызов стоит на своём месте

Спросить: **«Покажи суммы исков по годам и объясни их»**.

Ожидается сверху вниз:

1. текст до вызова, если модель что-то сказала;
2. свёрнутая строка «Строю график „Суммы исков по годам"»;
3. график — **внутри раскрытой строки**, не в конце сообщения;
4. текст после.

**Главное, что чинится**: в конце сообщения не должно остаться ничего, кроме
текста и отметок о разделах. Ссылки и графики — внутри своих вызовов.

Дальше по очереди:

| Действие | Ожидается |
|---|---|
| клик по строке вызова | раскрывается результат |
| раскрыть второй вызов | первый сворачивается |
| клик по строке, пока вызов идёт | ничего не происходит |
| два вызова подряд | две отдельные строки в порядке вызовов |

**Вызов с поиском**: спросить «Есть ли новости про эту компанию?» — ссылки
должны раскрываться внутри строки вызова, а не висеть в конце сообщения.

**Прерванный вызов**: задать вопрос с поиском и закрыть вкладку или уйти
на другую компанию, пока идёт вызов. Вернуться — вызов не должен остаться
крутящимся.

**Неудачный вызов**: временно сломать инструмент (например подставить
несуществующий ключ поиска) и убедиться, что строка отличается от удачной
и что по ней понятно: дальнейший текст на этот шаг не опирается.

## US3 — длинный ответ печатается плавно

Спросить: **«Разбери подробно все разделы отчёта»** — ответ на несколько сотен слов.

- Текст появляется словами, рывков к концу нет.
- Курсор набора виден, пока ответ идёт, и исчезает по окончании.
- Отлистать ленту вверх во время ответа — вниз не утаскивает.
- Прочитанное выше не дёргается и не перерисовывается.

## Вес сборки

```bash
npm --prefix src/web run build
```

Замер до правок: **776,17 КБ** (226,37 КБ в сжатии).

Разбор разметки добавил 165 КБ (51 КБ в сжатии) — это 23 % роста, слишком много
для первой загрузки. Поэтому чат грузится отложенно: он нужен только на экране
компании, а на домашнем экране его нет.

Итог: основная сборка **769,83 КБ** (224,69 КБ в сжатии) — легче, чем была
до фичи; отдельным куском `ChatPanel` — 171,05 КБ (53,05 КБ), он приезжает
при открытии компании.

Разбивать по самой разметке было бы ошибкой: ожидание срабатывало бы на каждый
текстовый блок и мигало прямо во время печати.

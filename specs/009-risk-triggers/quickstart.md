# Как проверить руками

## Триггеры

```bash
python3 -m pytest tests/test_triggers.py -q
```

Частоты закреплены тестом на настоящем наборе: если правило поедет,
тест назовёт новое число, а не молча пропустит.

На экране — три компании, они покрывают все состояния:

| ИНН | Что должно быть видно |
|---|---|
| `5032257375` МАКСМАРКЕТ | **пять триггеров**, включая «Статус с оговоркой» и «Светофоры молчат» |
| `8905068592` ООО «888» | ни одного, и явная формулировка «противоречий не найдено» |
| `781699330707` ИП АБРАМОВ | «отчётности нет» **не срабатывает** — у ИП её не бывает |

## Порядок по вопросу

Один контрагент, два вопроса, состав пунктов одинаковый, порядок разный:

```bash
curl -s -X POST localhost:8000/chat -H 'Content-Type: application/json' \
  -d '{"inn":"5032257375","message":"стоит ли давать отсрочку на 60 дней"}'
curl -s -X POST localhost:8000/chat -H 'Content-Type: application/json' \
  -d '{"inn":"5032257375","message":"почему светофор зелёный"}'
```

## Словарь

```bash
python3 scripts/build_field_dictionary.py    # пересобрать
python3 -m pytest tests/test_fields.py -q
```

На экране: открыть «Финансы» → «Подробнее». Ни одна подпись «Источник:»
не должна содержать квадратных скобок и латинских имён полей.

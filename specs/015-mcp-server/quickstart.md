# Как проверить руками

## Тесты

```bash
python3 -m pytest tests/test_mcp_server.py -q
```

## Сервер поднимается и отвечает

```bash
docker compose up -d --build mcp
scripts/mcp_probe.sh
```

Ожидается «MCP жив: 8 инструментов, набор подключён».

Голым curl список инструментов не получить: streamable-http требует сессию,
и `tools/list` без рукопожатия отвечает 400 «Missing session ID» — это
не поломка. Рукопожатие и делает скрипт.

## Порт не торчит наружу

```bash
curl -m 5 http://<адрес машины>:8001/mcp    # ожидается отказ в соединении
```

## Подключение к клиенту

По `docs/MCP.md`. Замерить: сколько шагов от «репозиторий склонирован»
до «клиент отвечает про контрагента» (SC-005).

Контрольный вопрос клиенту: **«что не так с ИНН 5032257375?»** Ожидается
банкротство, управляющий вместо директора и расхождение зелёных светофоров
с открытыми данными. Компании нет в памяти модели — значит ответ пришёл
из инструментов.

Второй: **«сравни 9714079997, 5032257375 и 7704310756 — с кем осторожнее»**.
Порядок должен совпасть с экраном сравнения. Балла быть не должно.

Третий: **«проверь по отчётам: у МАКСМАРКЕТ выручка 116 млрд и 900 судов»**.
Первое подтверждается, второе — нет.

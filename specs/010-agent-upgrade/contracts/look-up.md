# Контракт: инструмент `look_up`

## Модели

```
look_up(topic: str) -> текст
```

Описание перечисляет восемь тем с русскими названиями — иначе модель выбирает
по латинскому ключу и промахивается (проверено на `show_chart`: дважды выбрала
не тот график).

Возвращает поля темы словами словаря, а не путями:

```
Система налогообложения: ОСНО
Лицензии: 2 — «Эксплуатация взрывопожароопасных объектов» (действует),
«Перевозка опасных грузов» (действует)
```

Тема без данных отвечает явно:

```
По теме «госзакупки» данных о компании нет.
```

Несуществующая тема перечисляет доступные, а не молчит.

## Интерфейсу

Тем же блоком вызова, что и веб-поиск: заголовок «Запросил данные:
налогообложение», раскрывающееся содержимое. Иначе модель видит то, чего
не видит пользователь, и ответ станет нечем проверить.

## Потолок

Суды и взыскания отдаются сводкой. У остальных тем потолок такой же, как
у чтения страниц: продуктовое правило живёт в инструменте, а не в транспорте.

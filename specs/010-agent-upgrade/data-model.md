# Модель данных

## Topic — тема данных

| Поле | Что это |
|---|---|
| `key` | `финансы`, `суды`, `взыскания`, `надёжность`, `реквизиты`, `управление`, `деятельность`, `налоги` |
| `title` | как называется для модели |
| `fields` | пути словаря, входящие в тему |
| `summarize` | отдавать сводкой, а не целиком |

`summarize` стоит у судов и взысканий: замерено, максимум 52 294 токена
на компанию. Сводка берётся из `core/charts.py` — она уже посчитана и уже
показана пользователю, значит модель и он видят одно и то же.

## Claim — утверждение из ответа

| Поле | Что это |
|---|---|
| `number` | число, найденное в тексте ответа |
| `context` | фраза вокруг него — чтобы человек понял, о чём речь |
| `found` | нашлось ли это число в отчёте |

Утверждениями считаются числа, а не предложения: число проверяется
сопоставлением, предложение — только моделью.

## Verification — итог проверки

| Поле | Что это |
|---|---|
| `claims` | все найденные числа с отметками |
| `unverified` | сколько не нашлось в отчёте |
| `checked` | обращались ли к модели за второй ступенью |

`unverified = 0` при непустом `claims` — ответ полностью подтверждён числами.
Пустой `claims` означает «проверять было нечего», а не «подтверждено».

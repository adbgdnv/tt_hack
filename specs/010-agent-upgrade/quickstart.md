# Как проверить руками

## Модель и рассуждение

```bash
python3 -m pytest tests/test_llm.py -q
curl -s -X POST localhost:8000/chat -H 'Content-Type: application/json' \
  -d '{"inn":"5032257375","message":"стоит ли давать отсрочку на 60 дней"}'
```

Ответ должен связывать разделы между собой, а не перечислять их, и не быть
пустым. Пустой ответ означает, что рассуждение съело бюджет.

## Данные по темам

```bash
curl -s -X POST localhost:8000/chat -H 'Content-Type: application/json' \
  -d '{"inn":"5032257375","message":"какая у них система налогообложения"}'
```

Сегодня агент этого не знает. После правки — отвечает и показывает блоком,
что запросил тему «налоги».

Тяжёлый случай — компания с 1 744 производствами:

```bash
python3 -m pytest tests/test_topics.py -q
```

## Проверка утверждений

```bash
python3 -m pytest tests/test_verify.py -q
```

Ответ, все числа которого есть в отчёте, не должен вызывать модель повторно.

## Диалог

Поставить курсор в поле вопроса — диалог раскрывается. Esc — сворачивается,
переписка на месте.

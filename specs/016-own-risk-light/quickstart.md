# Как проверить руками

## Тесты

```bash
python3 -m pytest tests/test_compare.py tests/test_stream.py -q
```

## Ручка

```bash
curl -s localhost:8000/counterparties/5032257375/report \
  | python3 -c 'import json,sys; в=json.load(sys.stdin)["verdict"]; print(в["state"], "|", в["gaps"])'
```

Ожидается `осторожнее`.

## Экран отчёта

Открыть **5032257375** (МАКСМАРКЕТ) — три карточки в ряд: «Низкий»,
«Зелёный» и наша «осторожнее». Подпись у третьей называет открытые данные.

Открыть **9713021306** (ООО СТК «САЛМАН») — ничего не сработало, но связанных
организаций в данных нет. Ожидается «оценить нечем» серым, с припиской
«нет данных: связанные организации».

Открыть любого **ИП** — «нет отчётности» не должно превращать оценку
в «оценить нечем»: у ИП её не бывает по закону.

## Чат

Задать вопрос с расчётом: «во сколько раз денег меньше суммы сделки?».
Под ответом **не должно быть** строки «числа сверены с отчётом».

## Программный доступ цел

```bash
PYTHONPATH=src .venv/bin/python scripts/mcp_demo.py
```

Раздел «Проверка чисел» на месте: подтверждено 1 из 2.

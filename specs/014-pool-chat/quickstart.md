# Как проверить руками

## Проверка по нескольким отчётам

```bash
python3 -m pytest tests/test_verify.py tests/test_pool_chat.py -q
```

## Ручка

```bash
curl -s -N -X POST localhost:8000/compare/chat/stream \
  -H 'Content-Type: application/json' \
  -d '{"inns":["9714079997","5032257375","7704310756"],
       "message":"кому из них можно дать отсрочку на 60 дней?",
       "session_id":"пул-1"}' | grep '^event:' | sort | uniq -c
```

Ожидается: `token` много, `check` один, `done` один. Ответ называет все три
компании. Балла ни у одной быть не должно.

## Экран

Собрать пул из трёх компаний, задать вопрос под условия: «сумма 5 млн,
отсрочка 60 дней — кому можно?». Ожидается разбор всех трёх под эти условия.

Спросить «у кого какая система налогообложения» — в ленте блоки вызова
с указанием компании. В разборе одной компании имени в блоке нет: там оно
повторяет заголовок экрана.

Убрать компанию из пула — переписка сбрасывается.

Оставить в пуле одну компанию — разбор работает, а не отвечает «сравнивать
не с чем».

## Предел пула

```bash
curl -s -o /dev/null -w '%{http_code}\n' -X POST localhost:8000/compare/chat/stream \
  -H 'Content-Type: application/json' \
  -d "{\"inns\":[\"1\",\"2\",\"3\",\"4\",\"5\",\"6\",\"7\",\"8\",\"9\"],\"message\":\"?\"}"
```

Ожидается `422` и текст «Разбирать можно не больше 8 контрагентов сразу».
Тот же предел у `/compare` и у поля ввода на экране: девятую компанию туда
не добавить.

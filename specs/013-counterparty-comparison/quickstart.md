# Как проверить руками

Локально: бэкенд на 8000, `npm run dev` в `src/web` на 5173.

## Ручка

```bash
curl -s -X POST localhost:8000/compare -H 'Content-Type: application/json' \
  -d '{"inns":["9714079997","5032257375","7704310756","0000000000"]}' | python3 -m json.tool
```

Ожидается: `verdicts` от чистого к спорному, `summary` с заголовком
и подробностью, `not_found` с несуществующим ИНН. Ни `weight`, ни `score`,
ни `rank` в ответе быть не должно.

## Два режима

Открыть отчёт `5032257375`, нажать в шапке «Сравнение контрагентов»:
открывается экран сравнения, МАКСМАРКЕТ уже в пуле. Вернуться в «Проверку
контрагента» — тот же отчёт на месте.

## Пул

Добавить `9714079997` и `7704310756`. Ожидается три чипа с цветными точками.
Добавить `9714079997` второй раз — дубля быть не должно. Добавить `0000000000` —
чип остаётся с пометкой «не найден», а не пропадает молча. Убрать любой чип
крестиком.

Пул из одного: вывод говорит «сравнивать не с чем». Пустой пул: экран
объясняет, что делать.

## Вывод и порядок

Ожидается: заголовок «Из трёх чище других выглядит ООО "ТЕХПРОМ"», ниже
подробность с причиной у худшего. Карточки в порядке от чистого к спорному,
верхняя выделена фоном. **Ни одного числа-балла и ни одного порядкового
номера.**

У верхней карточки — число пройденных проверок; если по разделам данных нет,
это сказано словами.

## Переход к отчёту

Нажать «проверить →» у любой причины: открывается отчёт этой компании
на разделе, из которого причина взята. Вернуться в сравнение — пул на месте.

# Контракт конвейера

## Было

```
push в main
   ↓
[CI]          проверки стиля и тесты
   ↓  (отдельный запуск, слушает завершение CI)
[Deploy]
   ├─ окружение бэкенда → .env на сервере
   ├─ Выкатить бэкенд   → ssh: СБОРКА ОБРАЗА НА СЕРВЕРЕ
   ├─ Выкатить фронтенд → ssh: СБОРКА ОБРАЗА НА СЕРВЕРЕ  ← 894 МБ, нагрузка 27
   └─ статика превью + проверки
```

Сервер тратит пятнадцать-двадцать минут и всю свою память на работу, которая
не является его работой.

## Стало

```
push в main
   ↓
[checks]   стиль и тесты
   ↓
[build]    api и web параллельно, в раннере (4 ядра, 16 ГБ)
           каждый образ → реестр под двумя метками: коммит и «последний»
   ↓
[deploy]   окружение → вход в реестр по временному токену
           забрать образы по метке коммита → подменить контейнеры
           проверить, что отвечает → снять вход
```

Сервер только забирает готовое. Установка зависимостей и упаковка на нём
не происходят вовсе.

## Метки образов

| Метка | Зачем |
|---|---|
| по коммиту | выкатка ссылается на неё явно, и по ней же откатываются |
| «последний» | опора для кэша следующей сборки |

Выкатка **обязана** ссылаться на метку коммита, а не на «последний»: иначе
одновременные выкатки перетасуются, а откат станет невозможен — «последний»
всегда указывает на новое.

## Порядок внутри выкатки

Сохраняется тот, что есть сейчас, и по той же причине:

1. окружение (`.env`) — до всего, иначе новые ключи подхватятся только
   следующей выкаткой;
2. **бэкенд** — новый бэкенд шлёт поля, которых старый фронт не знает,
   и тот их игнорирует;
3. **фронтенд** — обратный порядок ронял страницу в белый экран;
4. проверки.

## Что должно остаться

- Не поднявшийся контейнер откатывается на предыдущий образ.
- Проверяются и статика, и API: контейнер, отдающий страницу без живого API,
  снаружи выглядит рабочим.
- Проверка здоровья идёт на IPv4, не на имя: в образе имя резолвится только
  в IPv6, а сервер слушает IPv4.
- Скрипты выкатки на сервере остаются root-owned и вне клона.

## Откат

Ручное действие: указать метку прошлого коммита и поднять контейнеры без сборки.
Не автоматический — по метрикам мы не откатываемся и не собираемся.

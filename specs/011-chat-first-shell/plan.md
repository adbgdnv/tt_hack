# Implementation Plan: Чат раздвигает отчёт, а не стоит сбоку

**Branch**: `011-chat-first-shell` | **Date**: 2026-09-05 | **Spec**: [spec.md](spec.md)

## Summary

Правка целиком в интерфейсе, бэкенд не меняется.

**Раскладка.** Двухколоночная сетка «отчёт слева, чат справа» уступает место
вертикальной: полоса разбора сверху во всю ширину, отчёт под ней в обычном
потоке. Раскрытие полосы двигает отчёт вниз само — этого не надо изображать,
это делает поток.

**Раздвижение.** Полоса раскрывается по фокусу в поле вопроса и сворачивается
по Esc. Состояние живёт в `ChatPanel`: раскрытие — свойство диалога, а не
страницы.

**Точка вместо плашки** — в `ReportSection` и `NewsBlock`, уже сделано первой
фазой и остаётся.

**Отменено против первой редакции**: строка из восьми точек под шапкой,
наложение с отчётом и карточки разделов внутри ленты. Первые два не нужны,
раз отчёт остаётся на экране; третье отменено по замерам.

## Project Structure

### Source Code

```
src/web/src/
  App.tsx                    правка: вертикальная раскладка вместо двухколоночной
  state.ts                   ← из первой фазы: цвет и слова состояния, одна таблица
  components/
    ChatPanel.tsx            правка: полоса, раскрытие по фокусу, Esc
    ReportSection.tsx        правка: точка вместо плашки (сделано)
    NewsBlock.tsx            правка: точка вместо плашки (сделано)
    BlockModal.tsx           без изменений: раздел открывается как прежде
  styles.css                 правка: полоса и её раскрытие
```

**Удаляется**: `SectionStrip.tsx` и `ReportOverlay.tsx` — их работу снова делает
сам отчёт, оставшийся на экране.

**Structure Decision**: раскладку держит поток документа, а не расчёт высот.
Полоса стоит перед отчётом обычным блоком: она растёт — отчёт уезжает вниз сам.
Вариант с фиксированной полосой и отступом у отчёта требовал бы согласовывать
два числа в двух местах и разъезжался бы при каждой правке.

**Почему состояние раскрытия в `ChatPanel`, а не в `App`.** Раскрытие — свойство
диалога: его включает фокус в поле, выключает Esc, и удерживает идущий ответ.
Все три условия видны только изнутри диалога.
